# Glowup-dashboard
A modern React-based Admin Dashboard built with **React.js** for managing products, tracking orders, and handling e-commerce store operations efficiently


## 🚀 Features
* **Product Management**: Add, update, and delete products (including image uploads).
* **Real-time Updates:** Fully integrated with production-ready REST APIs.
* **Responsive UI:** Clean and modern interface built for all screen sizes.
* **Error Handling:** Robust validation and API error tracking using browser console diagnostics.

## 🛠️ Tech Stack
* **Frontend:** React.js, HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)
* **State Management & Routing:** React Router
* **API Client:** Axios / Fetch API
